# Passkey

通过 Shizuku 管理 Android 14 及以上设备的通行密钥提供方和自动填充服务，界面使用 Miuix。

- 自动发现支持通行密钥的已安装应用，支持搜索和切换；只支持密码的提供方也会显示名称。
- 管理自动填充服务（`autofill_service`）。可选「同步自动填充」：所选应用带自动填充服务时一并切换，与系统设置一致。
- 逐个开关已启用的提供方，清理指向已卸载或已停用服务的失效项。
- 显示当前配置，写入后回读确认结果；查看 `dumpsys credential` 和 `dumpsys autofill` 的输出用于排查。
- 自动备份原配置（含自动填充服务），支持恢复及失败回滚。
- 快捷打开系统「密码、通行密钥和账号」、Google 密码管理器和 FIDO Bridge。
